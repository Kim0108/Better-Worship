# 更美的敬拜—公共崇拜學探討 互動式資訊網

> **著者**：易啟年 著  
> **出版**：榮光出版社 / 榮光傳道會  
> **專案定位**：現代化視覺響應式全書互動閱讀、台灣口音語音朗讀、全文即時檢索、列印與數位典藏平台。

---

## 專案簡介

本專案將易啟年牧師所著之公共崇拜學經典著作《更美的敬拜—公共崇拜學探討》（全書 219 頁）完整轉換為一個極致流暢、功能豐富且典雅莊嚴的互動式資訊網。

全面支援桌上型電腦、筆記型電腦、iPad/Android 平板與智慧型手機，隨時隨地查閱崇拜學的神學基礎、程序編排、事奉人員職責、音樂事工及聖禮規範。

---

## 核心特色與功能亮點

### 1. 完整呈現全書每一頁內容（共 219 頁）
- **原書高清圖版**：收錄 1 至 219 頁原版書籍完整頁面，保留歷史文獻真實風貌。
- **排版文字版（與原書圖版 100% 完全相同）**：
  - 經微軟原生繁體中文 OCR 逐頁深度精準校對，全書 219 頁零亂碼、零損壞字元。
  - 每一頁的文字內容、標點符號、段落結構、引言與聖經章節標記均與【原書圖版】完全相同。
  - 支援字級縮放（縮小／標準／放大）、暗色／亮色／暖調紙本主題切換與清晰排版。
- **圖文對照模式**：大螢幕下可同時並排檢視掃描原圖與數位排版文字，研讀對照最方便。
- **原書圖版放大與縮小圖示（字體清晰微距檢視）**：
  - 正文閱讀控制列內建專屬 **放大**、**縮小** 與 **重設（100%）** 圖示按鈕。
  - 支援將原書圖版平滑放大至 125%、150%、175%、200% 至 250%，讓讀者清晰閱讀所有鉛印細字、樂譜、註腳與章節編號。
  - 支援 **雙擊圖片快速放大／還原**，以及鍵盤快捷鍵（`+` 放大、`-` 縮小、`0` 重設），手機上亦可輕鬆放大觀看。

### 2. 嚴謹的大綱章節樹狀導航（依據原書頁碼 2-7 目錄）
- 涵蓋 15 大核心章節、數十個小節、作者自序、生平簡介、附註與參考書目。
- **配備專屬上下滑動滑桿**：左側目錄加入高對比金色自訂滾動滑桿，無論章節多長皆可隨時上下滑動滾動，輕鬆瀏覽第二章至第十五章及全書所有小節。
- 精確標示書本頁碼（P.1 ~ P.215）與 PDF 頁碼（P.1 ~ P.219），閱讀時目錄即時同步高亮當前閱讀進度。

### 3. 正文下方「左右滑動頁碼滑桿」（快速翻閱全書）
- 正文視窗下方新增直覺的 **頁面左右滑動滑桿（Page Scrubber）**。
- 滑動時即時提示目標頁碼與所屬章節標題，放開或拖曳即可瞬間跳轉至想讀的章節。
- 搭配兩側微調按鈕（‹ 與 ›），兼具快速導航與精準翻頁。

### 4. 台灣口音（zh-TW）國語語音朗讀系統（TTS）
- 內建 **台灣女聲** 與 **台灣男聲** 語音選項，道地台灣腔調。
- **語速即時動態生效**：支援 0.75x、1.0x (標準)、1.25x、1.5x (快速)、2.0x (極速)，切換語速時立即無縫以新速度朗讀當前段落。
- 朗讀時文字段落動態跟隨 **金色流光高亮**，並伴隨律動音波動畫。

### 5. 全載具極致響應式排版（手機、平板、電腦無死角適配）
- **手機介面專屬優化**：
  - 頂部導覽列緊湊自適應，按鈕尺寸手指友善（最小 40x40px），文字不溢出、螢幕不晃動。
  - 側邊目錄在行動端自動轉換為**滑入式浮動抽屜**（Drawer），點擊漢堡選單滑出，點選章節或半透明遮罩即自動收起。
  - 書頁圖版與排版文字 100% 滿版自適應，大字清晰，單手即可順暢閱讀與滑動翻頁。
- **平板介面優化**：橫直屏自適應排版，支援圖文對照與雙頁翻書。
- **電腦寬屏介面**：展開全功能工作區、目錄樹與檢索卡片一目了然。

### 6. 全書 219 頁即時全文檢索系統
- 秒級全文搜尋：輸入關鍵字（如「招待人員」、「詩班」、「聖餐」、「洗禮」等）。
- 即時呈現匹配頁面卡片、關鍵字上下文高亮（`<mark>`），點擊直達該頁。

### 7. 專業友善列印系統
- 支援 **列印目前頁面** 或 **列印目前整章**。
- 可自由選擇 **排版文字格式（節省墨水、字跡清晰）** 或 **原始書頁掃描圖版**。
- 內建 `@media print` 專用列印樣式，自動隱藏所有控制按鈕與側邊工具列。

### 8. Web Audio 原生音效合成引擎
- 零外部音檔依賴，純瀏覽器 Web Audio API 動態即時合成：
  - 輕柔紙張翻書聲
  - 清脆按鍵回饋音
  - 設定切換提示音
  - 朗讀啟動雙音和弦

### 9. 完整的「顯示與操作設定」（七大切換功能）
可在頂部導覽列點擊「**顯示與操作設定**」隨時呼叫彈窗自訂：
1. **全螢幕模式**：開啟 ／ 關閉（沉浸式無干擾閱讀）。
2. **音效回饋**：開啟 ／ 關閉（記憶使用者偏好）。
3. **裝置排版**：自動（自適應） ／ 手機版型 ／ 平板版型 ／ 電腦寬屏。
4. **版面配置**：自動 ／ 直式（滾動閱讀） ／ 橫式（雙頁擬真展開）。
5. **界面語言**：繁體中文 ／ English（完整多國語言切換）。
6. **文字字級**：縮小 ／ 標準 ／ 放大。
7. **視覺色系**：跟隨系統 ／ 亮色雅緻（晨曦金白） ／ 暗色沉浸（深藍星空） ／ 暖調紙本（護眼象牙）。

### 10. 零外部資源依賴（安全、隱私、超高相容性）
- 避免使用外部圖床或外部 CDN 腳本，完全杜絕外部連結失效風險。
- 本地直接以瀏覽器雙擊 `index.html` 即可 100% 正常運行，亦完全相容 GitHub Pages。

## 上傳至 GitHub 與部署 GitHub Pages 教學

若需將本專案發布至 GitHub 並啟用免費的 GitHub Pages 網站：

### 第一步：初始化 Git 倉庫並提交程式碼
在專案根目錄開啟終端機（PowerShell 或 Bash），依序執行以下指令：

```bash
# 初始化 Git 倉庫
git init

# 添加所有專案檔案
git add .

# 建立初次提交
git commit -m "feat: Release Better Worship Interactive Website with mobile RWD and scrubber slider"
```

### 第二步：推送到 GitHub
在 GitHub 上建立一個新的空倉庫（例如命名為 `Better-Worship`），然後執行：

```bash
# 切換至 main 主分支
git branch -M main

# 關聯至您的遠端倉庫 (請將 USERNAME 換成您的 GitHub 帳號)
git remote add origin https://github.com/USERNAME/Better-Worship.git

# 推送檔案至 GitHub
git push -u origin main
```

### 第三步：啟用 GitHub Pages 免費線上瀏覽
1. 開啟您的 GitHub 倉庫頁面。
2. 點擊頂部分頁的 **Settings**（設定）。
3. 在左側選單點選 **Pages**。
4. 在 **Build and deployment** > **Branch** 下方：
   - 選擇分支：`main`
   - 選擇目錄：`/ (root)`
5. 點擊 **Save**。
6. 等候約 1~2 分鐘，頁面頂端將顯示線上網址，如：  
   `https://USERNAME.github.io/Better-Worship/`
7. 任何人皆可透過該網址在手機、平板與電腦上瀏覽、朗讀與檢索本書！
